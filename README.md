# 📊 Personal Budget Tracker  

## 🎯 Project Idea  
The **Personal Budget Tracker** is a web application that helps users manage their income and expenses efficiently. It allows users to track, analyze, and plan their budget with an intuitive interface.  

## 🚀 Features  
✅ **Add Transactions** – Users can add income and expense entries easily.  
✅ **Categorize Transactions** – Assign categories like Food, Travel, Shopping, etc.  
✅ **Visual Analytics** – Display spending patterns through charts/graphs.  
✅ **Set Budget Goals** – Define budget limits and track progress.  
✅ **Edit/Delete Entries** – Modify or remove incorrect transactions.  
✅ **Responsive UI** – Clean and user-friendly interface optimized for all devices.  

## ⚙️ Tech Stack  
- **Frontend:** React with Vite  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Styling:** TailwindCSS  

## 📚 How It Works  
1. Users register/login to the platform.  
2. Add income and expense entries under different categories.  
3. View a summary of their budget and spending analytics.  
4. Modify or delete transactions as needed.
